# Aryan Kumar — Premium Editorial Portfolio

A high-performance personal portfolio built for **Aryan Kumar** (AI Engineer & AI Automation Specialist), inspired by the minimalist, media-led design aesthetic of [ASR Domain](https://world.asrdomain-5fb.workers.dev/).

---

## 🌟 Architecture & Features

- **Editorial Minimalist Aesthetic:** Deep obsidian/charcoal palette (`#09090b`), crisp typography, technical monospace metadata tags, and zero generic AI clichés (no neon gradients or floating robot vectors).
- **Interactive Walkthroughs:** Custom HTML5 video players for **FinSight AI** and **AI Invoice Audit Agent** with play/pause, seek, volume, and fullscreen controls.
- **AI Business Analyst Case Studies:**
  - **Study A:** $10.67M E-Commerce study covering 3,500 orders across Power BI dashboards and detailed 36-month Excel ledgers.
  - **Study B:** Dual-channel Warehouse & Retail distribution analysis.
- **Universal High-Resolution Lightbox:** Click-to-enlarge inspection for any dashboard, certificate, badge, or data model.
- **Authentic Credentials:** 6 verified professional certificates and 4 verified digital badges from Google, Coursera, Cisco, Kaggle, IIM Bangalore, and IIM Ahmedabad.
- **Profile & Resume:** High-resolution portrait and direct downloadable PDF of Aryan Kumar's official curriculum vitae.

## 🚀 Running Locally

1. **Install Dependencies** (if needed):
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```
   The production-ready static assets will be compiled into the `dist/` directory.

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```

## 🌐 1-Click Deployment Options

### Option 1: Vercel (Recommended)
1. Push this project to your GitHub repository: `https://github.com/ak7aryankuma/portfolio`
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository. Vercel automatically detects Vite:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Click **Deploy**.

### Option 2: Netlify
1. Go to [netlify.com](https://netlify.com).
2. Connect your GitHub repository.
3. Set **Build command** to `npm run build` and **Publish directory** to `dist`.
4. Click **Deploy site**.

### Option 3: Cloudflare Pages
1. Go to Cloudflare Dashboard → Workers & Pages → Create Application → Pages.
2. Select your repository, choose the **Vite** preset, and deploy.
